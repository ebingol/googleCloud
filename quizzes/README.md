# Beş soruluk quizler

**152 quiz · 760 soru · 6 bölüm · 43 PDF dosyası (41 benzersiz) + paylaşılan quiz**

Sorular İngilizce, açıklamalar Türkçe. Her set beş sorudur. `Select two/three` sorularında istenen sayıda seçenek işaretle; tam doğru seçenek kümesi 1 puan, diğer cevaplar 0 puandır. Toplam 5 puan üzerinden değerlendirilir.

Önce yalnızca soru dosyasını aç. Cevap anahtarları `answers/` altında ayrıdır. Sohbette `F01-01: 1A, 2BC, 3D, 4A, 5B` biçiminde yanıtlayabilirsin. Emin olmadığın cevapların yanına `?` koy.

Sorular yüklenen PDF sürümlerine göre hazırlanmış özgün çalışma sorularıdır; gerçek sınav soruları veya tam sınav kapsamı garantisi değildir. Sayfa numaraları PDF görüntüleyicideki **1 tabanlı dosya sayfasıdır**, slayt üzerindeki numara değildir. Güncel kota, fiyat veya ürün limiti iddiası olarak kullanılmamalıdır.
