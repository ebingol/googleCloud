# F04-02 — API credentials, service accounts and key risks

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. What is the difference between authentication and authorization?

**Select one.**

- A. Authentication and authorization are interchangeable names for the same step
- B. Authentication replaces the need to assign IAM permissions
- C. Authentication proves identity; authorization determines permitted actions
- D. Authentication determines allowed actions; authorization proves identity

## 2. What does an API key associate a request with in the module's explanation?

**Select one.**

- A. A service-account identity with a private key
- B. A verified human identity with inherited IAM permissions
- C. A project for billing and quota purposes
- D. An OAuth consent grant on behalf of a user

## 3. Which identity should an application use to call a Google API without end-user involvement?

**Select one.**

- A. A Google group used as a login credential
- B. An API key granting all IAM permissions by itself
- C. A personal account requiring interactive login for every call
- D. A service account

## 4. Which three risks of service-account keys are explicitly named?

**Select three.**

- A. Privilege escalation
- B. Automatic database sharding
- C. Permanent elimination of audit logs
- D. Identity masking
- E. Credential leakage

## 5. What does possession of a service account's private key effectively allow in the course's warning?

**Select one.**

- A. Accessing only public resources regardless of the account's roles
- B. Viewing only its display name without acting as it
- C. Authenticating only as the developer who downloaded the file
- D. Acting as that service account
