5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. What is Software Delivery Shield described as?

**Select one.**

- A. A source-code repository only
- B. An artifact-storage service only
- C. An end-to-end software supply-chain security solution
- D. A replacement for all application tests

## 2. Which two package languages are explicitly named for Assured Open Source Software?

**Select two.**

- A. Java
- B. Go
- C. Python
- D. JavaScript

## 3. Which service detects vulnerabilities in artifacts stored in Artifact Registry?

**Select one.**

- A. Artifact Analysis
- B. Cloud Deploy
- C. Cloud Monitoring
- D. Binary Authorization

- A. Only a successful image download
- B. Attestations about required processes completed for the image
- C. Only the source branch name
- D. Only the image tag's spelling

**Select two.**

- A. Replacing the container registry with a deployment target
- B. Delivery through a sequence of target environments
- C. Approvals and rollbacks
- D. Compiling every application's source code directly
