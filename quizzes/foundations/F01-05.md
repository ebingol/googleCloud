# F01-05 — Logging, CI/CD and incremental migration

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. How should a serverless application handle logs?

**Select one.**

- A. Rotate and archive log files inside each disposable instance
- B. Retain logs only in instance-local memory
- C. Send logs only during graceful shutdown
- D. Write events to stdout and let infrastructure collect them

## 2. What event starts the example continuous-integration process?

**Select one.**

- A. An operations team scheduling a monthly deployment
- B. A code update triggers a build and automated tests
- C. Manual approval of a production release
- D. Promotion of an existing image without a source change

## 3. Which statement distinguishes continuous deployment from continuous delivery in this module?

**Select one.**

- A. Continuous delivery automatically skips all production approvals
- B. Validated changes reach production automatically without a manual release-validation step
- C. Continuous delivery cannot generate deployable artifacts
- D. Continuous deployment requires a manual approval for every release

## 4. Which mapping of pipeline responsibilities is correct?

**Select one.**

- A. Cloud Deploy runs source control; Cloud Build stores databases; GKE signs users in
- B. Artifact Registry builds; Cloud Deploy stores images; Cloud Build serves production traffic
- C. Cloud Build builds; Artifact Registry stores artifacts; Cloud Deploy manages delivery
- D. Cloud Build and Artifact Registry both exclusively manage application runtime scaling

## 5. How does the strangler pattern reduce migration risk?

**Select one.**

- A. Keep every legacy feature and its replacement running permanently without changing routing
- B. Replace the entire legacy application before routing any production traffic
- C. A facade gradually routes functionality from the legacy application to new services
- D. Move all services simultaneously and validate afterward
