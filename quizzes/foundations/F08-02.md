- A. Cloud Trace analysis reports
- B. Log Analytics
- C. Logs Explorer only for individual entries
- D. Error Reporting error groups

## 2. Which tool streams system logs and metrics from Compute Engine VMs?

**Select one.**

- A. Cloud SQL Auth Proxy
- B. Cloud Trace client
- C. Ops Agent
- D. Error Reporting client

**Select one.**

- A. severity
- B. message
- C. component
- D. logging.googleapis.com/labels

**Select one.**

- A. Only a dashboard of VM machine types
- B. Only a trace for one slow request
- C. A logs-based metric and an associated alert
- D. Only a log-based alert on one matching entry
