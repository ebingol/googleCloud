# F08-01 — Observability services and the four golden signals

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which set contains the four golden signals in the module?

**Select one.**

- A. Latency, traffic, errors and saturation
- B. Errors, request size, project count and availability zone
- C. Traffic, CPU, storage class and region
- D. Latency, uptime, disk capacity and budget

## 2. Why should successful and failed request latency be distinguished?

**Select one.**

- A. Failed requests should never be recorded
- B. All failed requests are slower than every successful request
- C. Fast failures can make overall latency look misleadingly healthy
- D. Successful requests cannot be distinguished from failures

## 3. Which metric best exemplifies traffic for a web server in the course?

**Select one.**

- A. Percentage of memory capacity used
- B. HTTP(S) requests per second
- C. Average request duration
- D. Fraction of requests returning errors

## 4. What does saturation measure?

**Select one.**

- A. How many requests arrive per second
- B. The time required to serve a request
- C. How full or constrained system resources are
- D. The fraction of unsuccessful requests

## 5. Which service is the closest fit for dashboards, uptime checks and metric-based alerts?

**Select one.**

- A. Cloud Monitoring
- B. Error Reporting
- C. Cloud Trace
- D. Cloud Logging
