# F04-05 — Secret Manager

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which data is Secret Manager intended to store?

**Select one.**

- A. API keys, passwords and certificates
- B. Application log streams
- C. VM performance time series
- D. Container images and build artifacts

## 2. Which two statements about secret versions match the module?

**Select two.**

- A. Versions can hold different secret data
- B. Every existing version can be edited in place
- C. Adding a version overwrites every previous version
- D. Existing versions cannot be modified, but can be deleted

## 3. Which replication policy lets you specify where the secret data is stored?

**Select one.**

- A. single-copy-default
- B. public
- C. automatic
- D. user-managed

## 4. What does the resource path ending in versions/latest identify in the Python example?

**Select one.**

- A. The newest secret, regardless of its ID
- B. The latest version of every secret
- C. All secret versions across the project
- D. The latest version of the named secret

## 5. Which client method retrieves the secret version payload in the example?

**Select one.**

- A. access_secret_version
- B. get_secret
- C. create_secret
- D. list_secrets
