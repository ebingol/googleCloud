# F07-05 — Functions, jobs and compute-platform selection

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which two use cases are explicitly suggested for single-purpose functions?

**Select two.**

- A. A permanently running interactive desktop session
- B. A monolithic operating-system administration environment
- C. Webhook targets
- D. Lightweight ETL

## 2. How are Node.js function dependencies declared in the module's example?

**Select one.**

- A. Only a manually preinstalled VM image
- B. Only a ZIP containing all installed packages
- C. In package.json
- D. In an IAM policy binding

## 3. Which two statements correctly describe a Cloud Run job?

**Select two.**

- A. It exits when its work finishes
- B. It can run independent tasks in parallel and retry failures
- C. It must stay alive after completing all tasks
- D. It must start an HTTP server and listen on a port

## 4. Which product is named for running a Cloud Run job on a regular schedule?

**Select one.**

- A. Cloud Monitoring
- B. Cloud Tasks
- C. Cloud Build
- D. Cloud Scheduler

## 5. A developer-focused team wants stateless request handling with minimal infrastructure management. Which option best matches the comparison?

**Select one.**

- A. GKE Standard when node configuration is the main priority
- B. Cloud Run
- C. Self-managed Kubernetes on dedicated VMs
- D. Compute Engine with a self-managed application stack
