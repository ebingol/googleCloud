# F08-05 — Cloud Trace and Cloud Profiler

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. You need to see how request latency is distributed across service calls. Which tool matches?

**Select one.**

- A. Cloud Trace
- B. Cloud Monitoring uptime checks
- C. Cloud Profiler
- D. Error Reporting

## 2. How are traces and spans related?

**Select one.**

- A. A trace contains one or more spans for suboperations
- B. Spans describe only billing periods, not operation timing
- C. A trace has exactly one span and cannot contain suboperations
- D. A span always contains every trace in a project

## 3. Which approach is recommended when available for detailed application tracing?

**Select one.**

- A. Only writing plain text logs with no trace context
- B. Only increasing the VM CPU count
- C. OpenTelemetry with a Cloud Trace exporter
- D. Only automatic tracing without instrumenting internal calls

## 4. What does a dot's position represent in the Trace explorer scatter plot?

**Select one.**

- A. Request time and CPU frequency
- B. Request time and latency
- C. Error frequency and number of affected users
- D. Memory allocation and source-code line number

## 5. Which two kinds of information does Cloud Profiler attribute to application source code?

**Select two.**

- A. End-user passwords
- B. Memory allocation
- C. Billing-account payment details
- D. CPU usage
