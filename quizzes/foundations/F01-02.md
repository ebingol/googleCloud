# F01-02 — Microservices, asynchronous operations and loose coupling

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. How should microservice boundaries be chosen according to the module?

**Select one.**

- A. Match database-table boundaries exclusively
- B. Match programming-language boundaries
- C. Match business boundaries
- D. Match deployment-server boundaries

## 2. Which two properties distinguish the described microservices from a monolith?

**Select two.**

- A. All dependent services must release simultaneously
- B. Services can be deployed independently
- C. All services must maintain one shared scaling limit
- D. Services can scale independently

## 3. An uploaded image needs processing without blocking the user interface. Which design matches the example?

**Select one.**

- A. Upload to Cloud Storage and trigger a Cloud Run function or service
- B. Process the image synchronously before returning the upload response
- C. Store the image in Cloud SQL and wait for an administrator to process it
- D. Keep the image only in frontend memory until a batch server is available

## 4. Why place a message queue between an order service and an inventory service?

**Select one.**

- A. Decouple the services and buffer traffic spikes
- B. Force publishers to wait for all subscribers before accepting work
- C. Make service contracts unnecessary
- D. Guarantee that consumers never need retry logic

## 5. An email service receives name, age and email in a customer API response. Which fields should it bind to if only addressing an email?

**Select one.**

- A. Name and email
- B. Every returned field, including age
- C. Only email, while rejecting any payload containing additional fields
- D. All current and future fields in a strict shared response class
