# F02-03 — Cloud Shell, Cloud Code, emulators and Workstations

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which Cloud Shell resource persists across replacement session VMs according to the course?

**Select one.**

- A. The complete VM root filesystem indefinitely
- B. An unlimited persistent home directory
- C. The running VM and all its processes indefinitely
- D. 5 GB of persistent disk storage

## 2. Which two Cloud Code capabilities are explicitly listed?

**Select two.**

- A. Replacing every cloud service with a local emulator
- B. Local Cloud Run debugging with an emulator
- C. Managing all production IAM permissions without configuration
- D. Kubernetes YAML autocomplete and inline documentation

## 3. How can an application switch from a supported local emulator to the actual cloud service without rewriting business code?

**Select one.**

- A. Replace every library call with a direct REST request
- B. Create a separate production codebase for each emulator
- C. Recompile the application for a different programming language
- D. Change the relevant environment configuration used by the client library

## 4. Which command group manages the local service emulators described in the module?

**Select one.**

- A. gcloud beta emulators
- B. gcloud components emulator-config
- C. gcloud emulators production
- D. gcloud compute emulators

## 5. Which two properties describe Cloud Workstations?

**Select two.**

- A. Developers can connect through a browser, SSH or a local IDE
- B. The IDE and code run inside the VPC
- C. Every environment must run entirely on the developer's laptop
- D. Only a browser can access the environment; SSH and local IDEs are excluded
