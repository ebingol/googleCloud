# F01-01 — Cloud requirements, code, dependencies and configuration

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. A cloud application serves users worldwide. Which two design requirements are explicitly identified in the module?

**Select two.**

- A. Elastic scalability and high availability
- B. Region-independent compliance requirements
- C. Global reach
- D. Fixed-capacity provisioning as the default

## 2. How should external packages and their versions be managed?

**Select one.**

- A. Commit external package binaries to the code repository
- B. Leave package versions unspecified to simplify deployment
- C. Declare versions and install with a dependency manager
- D. Install dependencies manually without declaring them

## 3. Which configuration method allows the same tested code to move between environments?

**Select one.**

- A. Environment variables
- B. Different binaries with embedded settings for test and production
- C. Source-code constants rebuilt per environment
- D. A separate hard-coded configuration branch per environment

## 4. What is the stated benefit of keeping application code in a version-controlled repository?

**Select one.**

- A. Tracking changes and enabling CI/CD systems
- B. Replacing the need for release automation
- C. Automatically installing every external dependency
- D. Guaranteeing that all committed changes pass production tests

## 5. A compliance rule requires user data to stay in a specific region. Which cloud-design concern does this illustrate?

**Select one.**

- A. Security and compliance requirements
- B. Stateless worker lifecycle requirements
- C. Dependency isolation requirements
- D. Caching and content-distribution requirements
