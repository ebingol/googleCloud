# F03-02 — Bigtable and Cloud SQL

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which combination describes Bigtable's storage model?

**Select one.**

- A. A PostgreSQL-compatible relational database
- B. A serverless OLAP data warehouse
- C. A Redis-compatible in-memory cache
- D. A sparse wide-column NoSQL table

## 2. Which workload best matches the Bigtable use cases listed in the module?

**Select one.**

- A. A relational application requiring frequent multi-table joins
- B. An application requiring automatic end-user offline synchronization
- C. Large amounts of single-keyed data with high read/write throughput
- D. A small transactional dataset requiring multi-row relational transactions

## 3. Which three database engines are named for Cloud SQL?

**Select three.**

- A. SQL Server
- B. MySQL
- C. Oracle
- D. PostgreSQL
- E. Redis

## 4. Which tasks does the module explicitly say Google manages for Cloud SQL?

**Select one.**

- A. Only the database user interface, with replication managed entirely by the customer
- B. Business schema design, query semantics and application transactions
- C. Replication, failover and backups
- D. Every change to the application's data-access source code

## 5. Which component is named for easy and secure access to Cloud SQL instances?

**Select one.**

- A. Cloud Router
- B. AlloyDB Auth Proxy
- C. Cloud SQL Auth Proxy
- D. Identity-Aware Proxy
