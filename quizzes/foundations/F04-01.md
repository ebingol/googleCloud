# F04-01 — IAM principals, permissions and roles

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. What three elements does an IAM access decision connect?

**Select one.**

- A. User, password and browser session
- B. Service account, API key and OAuth client ID
- C. Project, region and billing quota
- D. Principal, role and resource

## 2. Which two entries are valid IAM principal types in the module?

**Select two.**

- A. Service account
- B. Cloud Storage bucket
- C. Compute Engine instance
- D. Google group

## 3. Which permission syntax matches the course?

**Select one.**

- A. service.verb.resource
- B. resource.service.verb
- C. role.principal.permission
- D. service.resource.verb

## 4. How are permissions granted to a user according to the role model?

**Select one.**

- A. Grant each standalone permission directly without using a role
- B. Add the user to every project automatically
- C. Grant a role containing the permissions
- D. Encode the desired permission into the user's email address

## 5. A predefined role grants more permissions than a workload needs. What option supports least privilege?

**Select one.**

- A. Grant all predefined roles for the service
- B. Create and maintain a custom role
- C. Use a broader basic role to avoid missing permissions
- D. Disable authorization checks for the workload
