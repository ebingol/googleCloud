# F01-04 — Caching, API gateways and federated identity

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. What should happen after a cache miss and recomputation?

**Select one.**

- A. Return the result and update the cache
- B. Invalidate the whole database to force a cache hit
- C. Return the result without ever refreshing the cache
- D. Retry the same cache lookup indefinitely without fetching backend data

## 2. Which service is described as managed in-memory application caching with Redis or Memcached?

**Select one.**

- A. Cloud Storage
- B. Cloud CDN
- C. Memorystore
- D. Bigtable

## 3. Which two benefits or capabilities are attributed to Cloud CDN?

**Select two.**

- A. Authenticate end users through federated identity providers
- B. Cache frontend content from supported backends
- C. Serve content closer to users through Google's edge network
- D. Provide durable transactional storage for all application state

## 4. A legacy backend cannot be migrated. Which service can provide a modern proxy facade with quotas, rate limits and analytics?

**Select one.**

- A. Cloud Load Balancing as a full API-management platform
- B. Cloud Endpoints as an application database
- C. Cloud CDN as a legacy-protocol translator
- D. Apigee

## 5. Why delegate user authentication to external identity providers?

**Select one.**

- A. Make all user data publicly accessible without identity checks
- B. Require users to authenticate with the application's shared service-account key
- C. Eliminate every application-level authorization check
- D. Avoid implementing, securing and scaling a proprietary authentication system
