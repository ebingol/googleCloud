5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which two request protocols are explicitly named for stateless Cloud Run containers?

**Select two.**

- A. Raw TCP on arbitrary ports as the stated request interface
- B. NFS as the incoming request interface
- C. gRPC
- D. HTTP

## 2. What does the source-based Cloud Run workflow use to turn supported source code into a container image?

**Select one.**

- A. Cloud Deploy
- B. Buildpacks
- C. Artifact Analysis
- D. Binary Authorization

## 3. What does the developer receive after deploying the web-request container in the example?

**Select one.**

- A. A unique HTTP(S) URL
- B. A Kubernetes control-plane endpoint to operate manually
- C. Only a container registry URL with no service endpoint
- D. A permanent VM IP requiring manual instance management

## 4. Which two GPU properties are stated in the uploaded Cloud Run slide?

**Select two.**

- A. A reservation is required before any GPU can be used
- B. GPU instances can scale down to zero
- C. GPU instances must always remain above zero
- D. One GPU per instance

**Select one.**

- A. A container image running on managed infrastructure
- B. A Kubernetes cluster the developer must administer
- C. Only source code interpreted directly without containers
- D. A VM image with a customer-managed OS
