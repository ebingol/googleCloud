# F07-02 — Kubernetes, GKE modes and infrastructure integration

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which Kubernetes component manages worker nodes and Pods?

**Select one.**

- A. A Cloud Load Balancer
- B. The control plane
- C. A container registry
- D. A single application Pod

## 2. Which two resources can containers in the same Pod share according to the module?

**Select two.**

- A. All service-account permissions across the cluster automatically
- B. Storage resources
- C. The full private memory of every other Pod
- D. Networking

## 3. Which GKE mode gives the customer more advanced infrastructure configuration flexibility?

**Select one.**

- A. Cloud Run jobs
- B. Cloud Run services
- C. Standard
- D. Autopilot

## 4. What does Autopilot manage in the module's description?

**Select one.**

- A. Only the control plane, with all node provisioning left to the customer
- B. Only the network load balancer
- C. Control plane, node pools and nodes
- D. Only the application's source code and tests

## 5. Which pairing matches GKE's described provisioning integrations?

**Select one.**

- A. Every Service with a new VM image; every Pod with a new database
- B. Persistent volumes with persistent disks; load-balancer Services with network load balancers
- C. Ingress resources with object versioning; volumes with DNS zones
- D. Persistent volumes with Cloud CDN; load-balancer Services with Secret Manager
