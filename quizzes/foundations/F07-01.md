# F07-01 — Compute Engine flexibility and instance groups

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which two machine-configuration options are described for Compute Engine?

**Select two.**

- A. Custom CPU and memory configurations
- B. Predefined machine types
- C. Only one fixed CPU-to-memory ratio for every application
- D. Only predefined machine types with no customization

## 2. Which workload is a good candidate for reclaimable VMs in this course?

**Select one.**

- A. A service requiring uninterrupted capacity with no failover
- B. A critical interactive session with no recovery mechanism
- C. A non-restartable process with unrecoverable state
- D. A batch workload that can tolerate interruption

## 3. What provides the common VM configuration for a managed instance group?

**Select one.**

- A. An instance template
- B. A Cloud Run revision
- C. A Kubernetes Service
- D. A snapshot alone with no configuration template

## 4. Which two requirements are specifically supported by Compute Engine's flexibility?

**Select two.**

- A. Only first-party software supplied by Google
- B. TCP protocols other than HTTP/HTTPS
- C. Only HTTP and HTTPS traffic
- D. Third-party licensed software

## 5. Why is Compute Engine suitable for lift-and-shift migrations?

**Select one.**

- A. It requires every application to be rewritten as a function
- B. It removes the customer's need to maintain the guest OS
- C. Existing VMs can be moved without redesigning the application
- D. It only accepts Kubernetes-native applications
