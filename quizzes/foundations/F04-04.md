# F04-04 — OAuth, IAP, Firebase Authentication and Identity Platform

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. An app must create resources on behalf of a user after the user consents. Which protocol fits?

**Select one.**

- A. An IAM role name passed as the user's password
- B. An API key alone
- C. OAuth 2.0
- D. A service-account key without user consent

## 2. What is IAP's main role in the course?

**Select one.**

- A. A central identity-based authorization layer for HTTPS applications
- B. A network-only firewall with no identity checks
- C. A service that exclusively issues database user passwords
- D. A library that requires every application to implement its own access gate

## 3. Which two features are explicitly provided by Firebase Authentication?

**Select two.**

- A. Ready-made sign-up/sign-in UI flows
- B. Automatic database schema migrations
- C. Authentication through passwords, phone and federated providers
- D. Managed VM operating-system updates

## 4. Which two enterprise capabilities are emphasized for Identity Platform?

**Select two.**

- A. Automatic database replication
- B. Multi-factor authentication
- C. SAML sign-in
- D. Container image vulnerability scanning

## 5. A team wants an access gate in front of an existing HTTPS application without writing custom access-control code. Which is the closest match?

**Select one.**

- A. Firebase Authentication SDK embedded as a full custom access layer
- B. Identity-Aware Proxy
- C. Cloud Monitoring uptime checks
- D. Cloud Load Balancing without identity-based authorization
