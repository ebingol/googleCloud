## 1. Which two interfaces are explicitly supported for Cloud API calls?

- A. SOAP-only requests for all services
- B. Direct SQL connections to every Google Cloud API
- C. gRPC requests
- D. HTTP requests with JSON payloads

**Select one.**

- A. gcloud compute instances list

- A. bq
- B. gcloud storage
- C. gsutil
