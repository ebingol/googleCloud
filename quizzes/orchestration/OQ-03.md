## 1. Which two Workflows features were accepted in your quiz?

**Select two.**

- A. A decentralized view with no central workflow definition
- B. Observable state for each execution
- C. Only simple business processes are appropriate
- D. Support for long-running processes

## 2. A business process includes waits and retries across several services. Which product most directly coordinates the process?

**Select one.**

- A. Cloud Storage used only to retain objects
- B. A service's local log file
- C. Cloud Tasks used only to deliver one HTTP task
- D. Workflows

## 3. A team needs to inspect a workflow run's current or final step. Which feature addresses this need?

**Select one.**

- A. Only a queue's destination URL
- B. Execution state and execution results
- C. Only an event's arbitrary payload format
- D. Only a project's display name

## 4. Which statement misrepresents Workflows according to the submitted quiz?

**Select one.**

- A. A workflow execution has observable state
- B. It is appropriate only for simple business processes
- C. A defined workflow coordinates processing
- D. Long-running processes are supported

## 5. What does observing a workflow execution let you distinguish?

**Select one.**

- A. A guarantee that every possible business input is valid
- B. A guarantee that no step will ever retry
- C. The progress/state of that run rather than merely knowing an event was emitted
- D. A guarantee that all external services will succeed
