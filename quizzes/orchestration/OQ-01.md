# OQ-01 — Cloud Tasks: delivery, scheduling, destinations and identity

5 soru. Her soruda seçilecek cevap sayısı belirtilmiştir.

**Kaynak türü:** Paylaştığın Choreography and Orchestration quizi ve belirtilen resmî dokümanlar. Bu konular mevcut Introduction to Microservices PDF’sinde anlatılmıyor.

## 1. Which two Cloud Tasks features were accepted in your submitted quiz?

**Select two.**

- A. The task creator has no control over its destination
- B. Exactly-once execution of every handler is guaranteed
- C. Scheduling a task for future delivery
- D. At-least-once delivery

## 2. A task might be executed more than once. Which handler property avoids duplicate side effects?

**Select one.**

- A. Assuming every delivery is unique
- B. Idempotency
- C. Generating a new irreversible charge for every retry
- D. Disabling all authentication

## 3. Using CreateTask for an HTTP task, what does the creator specify?

**Select one.**

- A. Only a topic, with no control over the handler
- B. The service and handler that should process it
- C. Only a workflow's current execution state
- D. Only an event schema, with no destination

## 4. What does a future scheduling time allow?

**Select one.**

- A. Remove all possible retries
- B. Guarantee exactly-once handler execution
- C. Defer delivery until a later scheduled time
- D. Convert a task into a broadcast to every service

## 5. Which identity distinction is accurate for authenticated HTTP tasks?

**Select one.**

- A. Cloud Tasks cannot attach authentication tokens to HTTP requests
- B. The configured service-account identity used for the token is distinct from the Cloud Tasks service agent's role in creating tokens
- C. The service agent's identity must always be the target-caller identity
- D. Adding a token automatically grants every target permission
