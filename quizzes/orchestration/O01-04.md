# O01-04 — Operational burden, network latency, testing and debugging

5 soru. Her soruda seçilecek cevap sayısı belirtilmiştir.

**Kaynak türü:** Introduction to Microservices PDF.

## 1. Which two challenges follow from having many deployable services?

**Select two.**

- A. Greater operational skill requirements
- B. Removal of all cross-service dependencies
- C. More deployments and potential failure points
- D. No need for authorization consistency

## 2. Which three activities does the PDF identify as crucial to automate?

**Select three.**

- A. Every API change without compatibility checks
- B. Testing
- C. Every business decision without review
- D. Builds
- E. Deployments

## 3. Why can an operation involving many microservice calls gain significant latency?

**Select one.**

- A. Network communication is always faster than local calls
- B. Microservices eliminate the need to transfer data
- C. Network calls replace many in-process calls
- D. Every API call necessarily removes all serialization overhead

## 4. Why can integration tests be harder even when individual unit tests are simpler?

**Select one.**

- A. Testing the whole system may require modeling the distributed production deployment
- B. Only the largest service needs to be tested
- C. Integration testing is unnecessary if services use APIs
- D. Unit tests automatically prove all network interactions correct

## 5. Why is debugging a request that crosses many services challenging?

**Select one.**

- A. All services necessarily use the same process stack
- B. Independent deployment prevents any distributed failures
- C. Separate logs automatically create a complete end-to-end trace
- D. Each service may produce separate logs, making the full call path hard to trace
