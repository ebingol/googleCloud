# O01-01 — Monoliths, SOA and the Enterprise Service Bus

5 soru. Her soruda seçilecek cevap sayısı belirtilmiştir.

**Kaynak türü:** Introduction to Microservices PDF.

## 1. Which combination characterizes the traditional monolith described in the PDF?

**Select one.**

- A. Only independently deployable services with separate databases
- B. A decentralized collection of unrelated APIs
- C. Only an event router without business logic
- D. UI, business logic and data access in one large application

## 2. What should each service in the described SOA implement?

**Select one.**

- A. Every enterprise function in one component
- B. Exactly one database column
- C. A discrete business function
- D. Only a network transport protocol

## 3. Which two responsibilities are attributed to the ESB?

**Select two.**

- A. Independent ownership of every service's business logic
- B. Protocol and data transformation
- C. Message routing
- D. Eliminating the need to test integrations

## 4. Why could ESB integration work delay multiple application teams?

**Select one.**

- A. Every service was guaranteed to deploy independently of integrations
- B. SOA prohibited communication between teams
- C. A central team became a shared integration bottleneck
- D. No service needed message transformation

## 5. Which two risks of changing the ESB are explicitly discussed?

**Select two.**

- A. Every update automatically isolates all failures
- B. Changing one integration may destabilize other applications
- C. Updating ESB software may break existing integrations
- D. All integration tests become unnecessary after the first release
