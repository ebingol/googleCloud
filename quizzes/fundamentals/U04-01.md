# U04-01 — Object storage, buckets, versioning and lifecycle

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which description distinguishes object storage from block storage?

**Select one.**

- A. Data and metadata are packaged as objects identified by keys
- B. Fixed-schema relational rows requiring joins
- C. A hierarchy of mutable files and directories only
- D. Raw disk sectors addressed as block devices

## 2. Which two choices are required when creating the bucket described in the course?

**Select two.**

- A. A Kubernetes namespace
- B. A globally unique name
- C. A mandatory VM machine type
- D. A geographic location

## 3. What does object immutability mean in the course?

**Select one.**

- A. Objects can never be replaced or deleted
- B. Changing content creates a new object version rather than editing it in place
- C. Object metadata cannot exist
- D. All previous versions are retained automatically regardless of settings

## 4. What does enabling object versioning add in the described workflow?

**Select one.**

- A. A guarantee of free storage for all versions
- B. A requirement to delete previous versions immediately
- C. The ability to retain and restore older object versions
- D. Automatic conversion to a relational database

## 5. Which two policies are examples of lifecycle management in the slides?

**Select two.**

- A. Keep only the three most recent versions
- B. Delete objects older than 365 days
- C. Recompile application source code on every read
- D. Change all IAM roles to Owner
