# U03-02 — Compute Engine, VM discounts and storage

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. What does Compute Engine let users create and run?

**Select one.**

- A. Only stateless HTTP containers
- B. Only a managed SQL schema
- C. Only single-purpose event functions
- D. Virtual machines with full operating-system functionality

## 2. Which workload is the best fit for Spot VMs in the course?

**Select one.**

- A. A workload needing uninterrupted capacity with no recovery
- B. A critical job that cannot resume or restart
- C. An interruption-tolerant batch job
- D. A process with unrecoverable state on termination

## 3. What distinguishes a committed-use discount in the module?

**Select one.**

- A. A fee waiver for changing machine names
- B. A discount earned automatically without any commitment
- C. A discount obtained only by allowing VM preemption
- D. A usage commitment for a one- or three-year term

## 4. Which storage option is described as transient local block storage with high performance?

**Select one.**

- A. Local SSD
- B. Filestore
- C. Cloud Storage bucket
- D. Regional persistent disk

## 5. Which option is explicitly described as block storage replicated in two zones?

**Select one.**

- A. Local SSD
- B. Cloud Storage object metadata
- C. Regional persistent disk
- D. Zonal persistent disk
