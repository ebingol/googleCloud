# U01-01 — Cloud computing characteristics and evolution

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which trait allows customers to provision computing resources without human intervention from the provider?

**Select one.**

- A. A requirement to buy resources before demand is known
- B. Manual provisioning by a provider's operator
- C. On-demand self-service
- D. Long-term fixed hardware allocation

## 2. What does elasticity mean in the course's definition?

**Select one.**

- A. Always reserving maximum capacity for the year
- B. Keeping a fixed instance count regardless of demand
- C. Increasing capacity but never reducing it
- D. Quickly increase or reduce resources as demand changes

## 3. Which two traits belong to the five cloud-computing characteristics shown?

**Select two.**

- A. All capacity must be permanently reserved in advance
- B. Resources are allocated from a shared provider pool
- C. Access resources over the internet
- D. Customers must know the exact physical host

## 4. What was rented in the first wave described as colocation?

**Select one.**

- A. A complete end-user SaaS application
- B. Physical space in a data center
- C. A managed application runtime with automatic scaling
- D. A set of serverless functions without any infrastructure responsibility

## 5. Which evolution order matches the course?

**Select one.**

- A. Container-based architecture, colocation, virtualized data center
- B. Virtualized data center, colocation, container-based architecture
- C. Colocation, virtualized data center, container-based architecture
- D. Colocation, container-based architecture, virtualized data center
