# U07-01 — Generative AI, LLMs and hallucination factors

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which relationship between generative AI and LLMs is stated in the module?

**Select one.**

- A. LLMs and all generative AI are identical categories
- B. Generative AI can generate text only
- C. LLMs are a language-focused subset of the broader generative AI category
- D. LLMs are only rule-based keyword lookup tables

## 2. Which two quantities explain large in large language model?

**Select two.**

- A. The required number of GPUs per user
- B. Number of parameters
- C. Training dataset size
- D. The length of every user prompt

## 3. Which sequence matches the training approach described?

**Select one.**

- A. Pre-train on a large dataset, then fine-tune for a specific purpose
- B. Fine-tune first, then discard the training data and weights
- C. Manually define every possible response without training
- D. Use only one zero-shot prompt to update all weights

## 4. Which three factors are explicitly listed as possible hallucination causes?

**Select three.**

- A. Insufficient context
- B. Insufficient constraints
- C. Noisy training data
- D. Defining clear task boundaries
- E. Providing a relevant worked example

## 5. A polished answer contains an incorrect claim. Does fluent wording alone establish correctness?

**Select one.**

- A. Yes; the model automatically verifies every claim against private data
- B. Yes; correct grammar guarantees factual accuracy
- C. No; generated output can still be wrong or misleading
- D. Yes; longer responses are always better grounded
