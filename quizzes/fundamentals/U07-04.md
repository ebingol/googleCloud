# U07-04 — Prompt engineering best practices and the Sasha example

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which instruction is more explicit for summarizing meeting notes?

**Select one.**

- A. Request a paragraph, a speaker/key-points list and action items
- B. Request any output format without identifying the task
- C. Provide only a document title with no action
- D. Ask only summarize this with no desired structure

## 2. Which two boundary-setting practices are recommended in the movie-agent example?

**Select two.**

- A. Use only prohibitions without a positive task
- B. Say what the model should do
- C. Require invented answers when no suitable result exists
- D. Provide an appropriate fallback when no recommendation is available

## 3. Why add a cloud-architect persona to a networking question?

**Select one.**

- A. Eliminate the need for network requirements
- B. Provide relevant context and focus
- C. Guarantee production validation of the design
- D. Automatically grant IAM permissions

## 4. How should long, complicated prompt sentences be improved according to the final best practice?

**Select one.**

- A. Combine all tasks into one very long sentence
- B. Remove every constraint and technical detail
- C. Break them into shorter sentences and simpler tasks
- D. Repeat the same vague request unchanged

## 5. Which architecture does Gemini propose in the final Sasha example in this document?

**Select one.**

- A. A single isolated subnet with no inter-VPC connections
- B. A stand-alone public bucket with no network topology
- C. Hub-and-spoke
- D. A full mesh as the specific proposed example
