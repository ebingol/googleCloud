# U02-02 — Folders, organizations and IAM policy inheritance

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. What is required to use folders in the described hierarchy?

**Select one.**

- A. A Kubernetes cluster
- B. A billing budget alert
- C. An organization node
- D. A VPC peering connection

## 2. Which two items can a folder contain?

**Select two.**

- A. Other folders
- B. Regions as direct hierarchy containers
- C. Billing invoices as child resource containers
- D. Projects

## 3. Why place projects managed by the same team under one folder?

**Select one.**

- A. Apply common policies once and inherit them below
- B. Remove the organization's inherited policies
- C. Make both projects share one immutable project ID
- D. Prevent project-specific policies from existing

## 4. A principal receives a role on a folder. Where does the resulting allow policy apply in the described model?

**Select one.**

- A. Only the folder's own metadata
- B. The folder and descendant resources
- C. Only projects outside the organization
- D. Only resources created before the grant

## 5. What happens when an applicable deny policy conflicts with an allow grant for the same permission?

**Select one.**

- A. Both policies are ignored when they conflict
- B. The most recent allow grant always wins
- C. The deny policy takes precedence
- D. The broader allow role always wins
