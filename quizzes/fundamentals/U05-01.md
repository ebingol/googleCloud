# U05-01 — Container architecture and microservice scaling

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. What does a container package in the module's definition?

**Select one.**

- A. Only source code without runtime dependencies
- B. Application code and its dependencies
- C. Only an instance template with no executable code
- D. A complete independent guest operating system for every instance

## 2. Which two host components are identified as necessary to run containers?

**Select two.**

- A. An OS kernel that supports containers
- B. A full separate guest OS per container
- C. A dedicated physical machine for each container
- D. A container runtime

## 3. Why can containers be created quickly in the course's explanation?

**Select one.**

- A. They boot a new guest OS for every process
- B. They preallocate a full VM for each request
- C. They require a complete disk-image migration first
- D. Creation needs only a few system calls and starts like a process

## 4. Which action illustrates scaling the same containerized web application horizontally?

**Select one.**

- A. Rebuild the same single instance with a new image tag
- B. Run additional instances of its container
- C. Increase only the CPU of its single host
- D. Rename the existing container without adding instances

## 5. Which two benefits are listed for an application composed of function-specific containers?

**Select two.**

- A. Every component must scale equally
- B. Every change requires replacing all hosts together
- C. Independent scaling across hosts
- D. Modularity
