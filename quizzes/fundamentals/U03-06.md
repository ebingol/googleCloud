# U03-06 — Cloud DNS and Cloud CDN

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. What does DNS translate in the course's description?

**Select one.**

- A. Internet hostnames into addresses
- B. Packets into encrypted disk blocks
- C. Project names into IAM permissions
- D. Source code into container images

## 2. Which two properties are attributed to Cloud DNS?

**Select two.**

- A. Only manual configuration with no API
- B. A single nonredundant physical DNS server
- C. Programmatic zone and record management through CLI or API
- D. Serving published DNS information from redundant global locations

## 3. What does edge caching do?

**Select one.**

- A. Store content closer to end users
- B. Store all content exclusively at the original backend
- C. Replace every application database with RAM
- D. Rebuild content for every user request

## 4. Which two benefits of Cloud CDN are explicitly stated?

**Select two.**

- A. Reduced load on content origins
- B. Guaranteed removal of all origin storage costs
- C. Automatic resolution of every application bug
- D. Lower network latency

## 5. Which component is set up before enabling Cloud CDN with the checkbox shown in the module?

**Select one.**

- A. A Cloud SQL replica
- B. A Secret Manager replication policy
- C. A Dedicated Interconnect circuit
- D. An Application Load Balancer
