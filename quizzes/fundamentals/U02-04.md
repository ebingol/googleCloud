# U02-04 — Service accounts as identities and resources

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. A VM application must access Cloud Storage without end-user involvement. What identity fits?

**Select one.**

- A. The bucket's name alone
- B. A shared personal password embedded in code
- C. A service account
- D. An API key assumed to grant all storage permissions

## 2. How are service accounts identified in the course?

**Select one.**

- A. By a bucket's globally unique name
- B. By email addresses
- C. By a personal password alone
- D. By a VM's external IP address only

## 3. Which statement captures the dual nature of a service account?

**Select one.**

- A. It is both an identity and an IAM-managed resource
- B. It is only a human user
- C. It can act as an identity but cannot be managed as a resource
- D. It cannot have an IAM policy attached

## 4. What determines the permissions a VM application receives through its service account?

**Select one.**

- A. The VM's display name
- B. The programming language chosen
- C. Roles granted to that service account
- D. The project's geographic region alone

## 5. Why might two people receive different roles on the same service-account resource?

**Select one.**

- A. Every manager must be an organization owner
- B. One needs to manage it while the other only needs to view it
- C. Viewing and management cannot be separated
- D. Every viewer needs the private key
