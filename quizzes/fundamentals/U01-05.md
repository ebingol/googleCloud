# U01-05 — Infrastructure security layers

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which two protections belong to the hardware infrastructure level in the course?

**Select two.**

- A. Application-level input validation
- B. Physical premises security
- C. Per-request application role assignment
- D. Secure boot stack

## 2. Which traffic is explicitly described as encrypted at the service deployment level?

**Select one.**

- A. Infrastructure RPC traffic between data centers
- B. Only user passwords stored on disk
- C. Only data stored in backups
- D. Only the customer's billing export

## 3. Which infrastructure component terminates TLS connections and applies DoS protections for internet-facing services?

**Select one.**

- A. Cloud CDN origin storage
- B. Google Front End
- C. Cloud DNS
- D. Cloud Router

## 4. Which two operational-security practices are explicitly listed?

**Select two.**

- A. Monitoring and limiting privileged employee activity
- B. Two-party review of new code
- C. Unrestricted privileged access without monitoring
- D. Shared administrator passwords for all operators

## 5. Why may Google's identity service ask for additional information during sign-in?

**Select one.**

- A. Risk factors such as an unfamiliar device or location
- B. A static budget threshold was crossed
- C. The application's container image grew in size
- D. The user's project name changed
