# U04-03 — Cloud Storage access, transfers and integrations

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. What is the course's general access-control guidance for object data?

**Select one.**

- A. Use only the bucket name as an access credential
- B. Use IAM, with ACLs where finer object-level control is needed and supported
- C. Treat storage class as the authorization policy
- D. Make objects public before applying any IAM role

## 2. Does mounting a bucket with a filesystem tool make Cloud Storage fundamentally a native filesystem?

**Select one.**

- A. Yes; it becomes native block storage
- B. No; it remains object storage exposed through a filesystem-like interface
- C. Yes; every object becomes an SQL row
- D. Yes; it removes object immutability entirely

## 3. Which service schedules large batch transfers from another provider or HTTP(S) endpoint to Cloud Storage?

**Select one.**

- A. Storage Transfer Service
- B. Transfer Appliance
- C. Cloud SQL Auth Proxy
- D. Cloud CDN

## 4. What happens in the Transfer Appliance workflow?

**Select one.**

- A. Load data onto a leased device and ship it to an upload facility
- B. Stream data continuously through a Cloud VPN tunnel
- C. Move data only through a browser upload form
- D. Replicate a database solely through SQL queries

## 5. Which two examples of Cloud Storage integration are explicitly listed?

**Select two.**

- A. Store Compute Engine images and startup scripts
- B. Import/export tables with BigQuery and Cloud SQL
- C. Automatically convert IAM policies to object versions
- D. Schedule Pods through object metadata
