# U01-02 — IaaS, PaaS, SaaS and managed services

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which offering provides raw compute, storage and network capabilities?

**Select one.**

- A. PaaS
- B. A finished web application
- C. SaaS
- D. IaaS

## 2. Which service model binds application code to libraries that provide access to needed infrastructure?

**Select one.**

- A. IaaS
- B. Colocation
- C. PaaS
- D. SaaS

## 3. Which pair of examples matches the module?

**Select one.**

- A. Compute Engine: SaaS; App Engine: IaaS
- B. Compute Engine: IaaS; App Engine: PaaS
- C. Gmail: IaaS; Compute Engine: PaaS
- D. Compute Engine: PaaS; App Engine: SaaS

## 4. What does SaaS deliver to an end user?

**Select one.**

- A. Only raw compute and storage
- B. A complete application consumed over the internet
- C. Only physical data-center floor space
- D. Only application libraries with no completed application

## 5. What is a stated reason for adopting managed resources and services?

**Select one.**

- A. Eliminate the need to develop application logic
- B. Require more direct management of physical servers
- C. Replace business requirements with fixed provider defaults
- D. Spend less effort maintaining infrastructure and more on business goals
