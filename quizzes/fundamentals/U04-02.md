# U04-02 — Storage classes, Autoclass and encryption

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which class is matched with frequently accessed hot data?

**Select one.**

- A. Coldline
- B. Archive
- C. Standard
- D. Nearline

## 2. Which class is matched with access about once per month or less?

**Select one.**

- A. Nearline
- B. Standard
- C. Coldline as the monthly class
- D. Archive as the monthly class

## 3. Which pair of access patterns matches the uploaded storage-class slide?

**Select one.**

- A. Coldline: daily; Archive: monthly
- B. Archive: hot data; Standard: annual archives
- C. Coldline: monthly; Nearline: every 90 days
- D. Coldline: about every 90 days; Archive: about once per year

## 4. How does Autoclass react to object access patterns in the module?

**Select one.**

- A. Keep every object in its original class regardless of access
- B. Move unused data colder and accessed data to Standard
- C. Move accessed data to Archive permanently
- D. Require manual class selection for every access event

## 5. Which two encryption facts are stated for Cloud Storage?

**Select two.**

- A. HTTPS/TLS for data in transit between customer and Google
- B. Unencrypted transport as a mandatory requirement
- C. Plaintext-at-rest storage as the default
- D. Server-side encryption before writing data to disk
