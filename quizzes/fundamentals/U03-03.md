# U03-03 — VM scaling and load-aware capacity

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. What does horizontal scaling change?

**Select one.**

- A. Only the size of an attached disk
- B. Only the maximum number of IP addresses in a subnet
- C. The number of VM instances serving the application
- D. Only the CPU and memory of one existing VM

## 2. What does the described autoscaling feature use to add or remove VMs?

**Select one.**

- A. Load metrics
- B. The alphabetical order of VM names
- C. Only the number of IAM users
- D. Only source repository size

## 3. What complements autoscaling by distributing incoming requests among VMs?

**Select one.**

- A. Identity federation
- B. Object versioning
- C. Load balancing
- D. DNS record versioning

## 4. Which two workloads are specifically mentioned as candidates for very large VMs?

**Select two.**

- A. CPU-intensive analytics
- B. In-memory databases
- C. Only user sign-in federation
- D. Only static object archiving

## 5. A service moves from four VMs to forty VMs as demand grows. What combination addresses capacity and request distribution?

**Select one.**

- A. Autoscaling plus load balancing
- B. Only raising a billing budget threshold
- C. Only changing DNS records with no added capacity
- D. Vertical resizing of a single VM without request distribution
