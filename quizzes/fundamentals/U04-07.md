# U04-07 — Choosing among storage products

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. An application needs immutable binary objects such as photos and videos. Which product matches?

**Select one.**

- A. Firestore as binary-object hosting
- B. Cloud Storage
- C. Cloud SQL
- D. Spanner

## 2. An existing web application needs managed relational SQL support with familiar engines. Which product matches?

**Select one.**

- A. Cloud Storage
- B. Bigtable
- C. Cloud SQL
- D. Firestore

## 3. An OLTP workload requires relational SQL and horizontal scaling to very large capacity. Which product matches the comparison?

**Select one.**

- A. Cloud Storage
- B. Cloud SQL without horizontal scale requirements
- C. Bigtable without relational transactions
- D. Spanner

## 4. A mobile app needs real-time results and offline query support. Which product matches?

**Select one.**

- A. Cloud Storage
- B. Bigtable
- C. Cloud SQL
- D. Firestore

## 5. The uploaded comparison table lists 1 MB as the maximum unit size for which product?

**Select one.**

- A. Firestore
- B. Cloud Storage
- C. Spanner
- D. Cloud SQL
