# U01-03 — Global network, regions, zones and fault tolerance

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which relationship matches Google Cloud geography in the module?

**Select one.**

- A. A multiregion is a single availability zone
- B. A zone contains several regions
- C. A region contains multiple zones
- D. Every region consists of exactly one zone

## 2. A Compute Engine VM is launched in europe-west2-a. What kind of location is this?

**Select one.**

- A. An organization
- B. A region
- C. A multiregion
- D. A zone

## 3. What is the primary benefit of spreading resources across several zones in one region?

**Select one.**

- A. Automatic translation of the application
- B. Protection against every region-wide disaster
- C. Improved fault tolerance
- D. Guaranteed lower prices in each zone

## 4. Which two reasons are given for using resources in several regions?

**Select two.**

- A. Automatically remove all application security risks
- B. Bring applications closer to worldwide users
- C. Guarantee lower prices than a single-region deployment
- D. Protect against an entire region becoming unavailable

## 5. Why are content caching nodes placed around the world?

**Select one.**

- A. Force all users to contact the same origin data center
- B. Respond from locations that reduce latency for users
- C. Ensure content is stored only in one zone
- D. Replace durable origin storage entirely
