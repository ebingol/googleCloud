# U03-01 — VPC scope and subnets

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which description best matches a VPC?

**Select one.**

- A. An isolated private cloud-computing environment hosted within a public cloud
- B. A public subnet shared without isolation among all customers
- C. A physical private data center that the customer must own
- D. A container runtime with no network functionality

## 2. What is the scope of a Google Cloud VPC network in the module?

**Select one.**

- A. Global
- B. Zonal
- C. Regional
- D. Per-instance only

## 3. What is the scope of a VPC subnet?

**Select one.**

- A. Regional
- B. Per-Pod only
- C. Zonal
- D. Global

## 4. Which two statements about the subnet example are correct?

**Select two.**

- A. VMs in different zones of the same region can use the same subnet
- B. Expanding the range always deletes existing VMs
- C. A subnet's IP range can be expanded without affecting configured VMs
- D. A subnet necessarily spans every region in a VPC

## 5. Which capability is explicitly included in VPC networking?

**Select one.**

- A. Static routes to specific destinations
- B. Source-code compilation
- C. End-user password recovery
- D. Automatic relational schema conversion
