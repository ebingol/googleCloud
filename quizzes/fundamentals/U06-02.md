# U06-02 — Cloud Run functions and event-driven applications

5 soru. Soruların her birinde kaç seçenek seçileceği belirtilmiştir.

## 1. Which workload best matches Cloud Run functions in the module?

**Select one.**

- A. A non-event-driven physical network appliance
- B. A permanently interactive desktop session
- C. A continuously administered general-purpose OS
- D. Resize an image when a new file is uploaded

## 2. Which two services are listed as asynchronous event sources for functions?

**Select two.**

- A. Pub/Sub
- B. Cloud Storage
- C. Cloud Billing Reports as a listed source
- D. Cloud DNS as a listed asynchronous event source

## 3. Which invocation method is explicitly associated with synchronous execution?

**Select one.**

- A. HTTP invocation
- B. Only Pub/Sub event delivery
- C. Only an offline file-transfer appliance
- D. Only a Cloud Storage event trigger

## 4. What programming unit should a function generally implement according to the module?

**Select one.**

- A. A manually managed always-running server
- B. A small, single-purpose piece of business logic
- C. The entire guest operating system
- D. Every application component forced into one function

## 5. Why use a managed function for a rare image-processing event?

**Select one.**

- A. Require a user to manually start a VM for each image
- B. Disable event triggers and rely only on monthly batches
- C. Run the event-driven code without provisioning a server or runtime environment yourself
- D. Keep maximum VM capacity allocated permanently
