- A. A cluster
- B. A Deployment
- C. A Pod
- D. A node pool

- A. When they need completely isolated networking

**Select one.**

- A. Deployment
- B. Ingress
- C. Node pool

- A. The container image's registry address
- B. Service

- A. kubectl scale changes a Deployment's replica count
- B. bq query changes replica counts
- C. kubectl apply -f applies a configuration file
